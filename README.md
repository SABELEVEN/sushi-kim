# СушиХОТ — сайт доставки суши

Одностраничный сайт (HTML/CSS/JS в одном файле `index.html`, без сборки — открывается прямо в браузере).

## Структура
- `index.html` — вся разметка, стили и логика (меню, корзина, форма)
- `images/` — сюда нужно положить фото блюд и категорий (сейчас их нет, вместо фото показываются эмодзи-плейсхолдеры)

## Что уже реализовано
- Каталог из 7 категорий (морсы, роллы, запечённые, темпурные, закуски, сеты, пиццы)
- Корзина с подсчётом суммы, минимальным заказом (800 ₽) и бесплатной доставкой от 1500 ₽
- Оформление заказа через WhatsApp (номер задан в `RESTAURANT_WHATSAPP`)
- Адаптивная вёрстка (десктоп с сайдбаром / мобильная версия с топбаром)

## Что стоит доделать дальше
- Добавить реальные фото в `images/` (имена файлов уже прописаны в данных `MENU`)
- Заменить тестовые контакты, адрес и номер телефона на реальные
- Заменить тестовые отзывы на реальные
